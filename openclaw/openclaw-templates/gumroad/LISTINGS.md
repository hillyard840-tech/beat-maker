## Updating the zips

Whenever you change a template or the license:
1. Edit the files in `openclaw-templates/<template>/`, and bump `version` in its `package.json`.
2. Run `OPENCLAW_EXPERIMENTAL_CLAWS=1 openclaw claws validate <template>` and `openclaw claws build <template> --out <template>-<version>.tgz`.
3. Make a new zip containing a `<template>/` folder with `package/` (from the `.tgz`), `SETUP.md`, `config/` and `LICENSE.txt`.
4. In Gumroad, replace the file on the product. Existing buyers can download the new version from their library.
